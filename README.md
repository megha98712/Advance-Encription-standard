🔐 AES Encryption Web Application

A modern and responsive AES (Advanced Encryption Standard) web application with a secure-looking cybersecurity UI, login system, AES encryption/decryption functionality, animated background effects, and history tracking.

🚀 Features
🔑 Login Interface
🔐 AES Encryption & Decryption
🛡️ Supports AES-128 / AES-192 / AES-256
📋 Copy Encrypted/Decrypted Text
🕘 Encryption History
✨ Animated Star Background

⚙️ How It Works
🔐 Encryption Process
Enter plain text
Enter encryption key
Select AES type
Click Encrypt
Ciphertext is generated
🔓 Decryption Process
Paste ciphertext
Enter the same key
Select correct AES type
Click Decrypt
Original text is recovered
🔒 AES Key Sizes
AES Type	Key Length	Rounds
AES-128	128 bits	10
AES-192	192 bits	12
AES-256	256 bits	14
